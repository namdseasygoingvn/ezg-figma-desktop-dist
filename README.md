# EZG Figma Desktop — releases

Downloads and auto-update feed for EZG Figma Desktop. Get the latest build from [Releases](https://github.com/namdseasygoingvn/ezg-figma-desktop-dist/releases/latest).

The source is private. Each push to its `main` dispatches `.github/workflows/release.yml` here, which builds macOS and Windows and publishes a release with `latest.json`.
